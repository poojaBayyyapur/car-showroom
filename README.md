# WEGO – Premium Car Showroom 🚗

WEGO is a modern and stylish car showroom website featuring a glassmorphism design, premium car collections, and interactive features.

## 🌐 Live Website

[Visit WEGO – Premium Car Showroom](https://poojabayyyapur.github.io/car-showroom/)

## ✨ Features

- Attractive homepage with animated car background
- Modern glassmorphism design
- Premium car brands and luxury models
- Multiple car collections across different budgets
- Low-to-High and High-to-Low price sorting
- Interactive car details and features
- Premium brands and happy clients sections
- Deals, Location, Services and About sections
- Responsive website design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
